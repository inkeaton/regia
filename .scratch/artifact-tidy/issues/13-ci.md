## Question

What shows that the artifact builds somewhere other than the authors' machines?

Add `.github/workflows/ci.yml` on branch `1.0` (push and pull requests), running on Ubuntu with caches for uv, Gradle and npm. Steps:

1. `make setup`
2. `make test`
3. regenerate agents and check that the minds build passes (`make minds`)
4. `make qscores`, failing on a reference diff
5. a compile-benchmark smoke run with `--reps 1`
6. `make editor`

Godot and the full and runtime benchmarks don't run in CI (see Out of scope). CI has to run green before the ticket closes, which needs a push, and that push needs the user's go-ahead.
